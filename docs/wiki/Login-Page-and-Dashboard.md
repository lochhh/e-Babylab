In order to access the e-Babylab, login credentials are required for every user and are only provided by a site administrator.

*Login page*
![Login page](https://github.com/user-attachments/assets/66266452-c075-48d8-b73c-49aabae9d904)

Upon successful login, depending on the role assigned to a user, one of two dashboard views is presented: 
the normal user's view or the site administrator's view. The dashboard displays e-Babylab's functionality a user has access to and
their recent actions (if any).
